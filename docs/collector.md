# 収集の拡張機能の使い方（運営用）

お手本にする声（VTuber・配信者・キャラなど）の配信や動画を、運営が自分の Chrome で再生しながら、声を 30 秒ずつ数字にします。測った数字は、声のページで比べる相手になり、声真似の点数のページでもお手本として選べます。

- 音は保存も送信もしません。残すのは数字・動画 ID・時刻だけです（Chrome の拡張機能の保存場所）。
- 再生は人が行います。拡張機能は動画を開いたり、再生したり、飛ばしたりしません（YouTube の規約の「自動化された手段」を避けるため）。
- 広告中・一時停止中・シーク中・再生速度が 1 倍でない間は、測りません。

## 入れ方

1. `npm run build:collector` を実行する（`collector/dist` ができる）。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」を入れる。
3. 「パッケージ化されていない拡張機能を読み込む」で `collector/dist` を選ぶ。
4. `data/catalog.json` を変えたら、もう一度 1 を実行し、拡張機能の「更新」を押す（お手本の一覧は拡張機能の中に入る）。

## 測り方

1. `data/catalog.json` の `voices` に、測るお手本を足しておく（例: `{"id": "v-0001", "name": "…", "group": "所属や作品名", "links": {"profile": "公式ページの URL"}}`）。
2. YouTube でその声の配信や動画を開く。右下に「voice-twin 収集」の板が出る。
3. 板に ID を入れて「測る」を押し、動画を再生する。
4. 30 秒ごとに「記録しました」か「除きました（理由）」が出る。
5. 終わったら「書き出し」を押す。ダウンロードされた `<ID>.json` を `data/voices/` に入れる。
6. `npm run build:voices` で代表値（`data/profiles.json`）を作る。3 つ以上そろったら `npm run eval` で照合のモデルを作る。サイトをビルドし直す。

## 配信の選び方

- その声だけが長く続く物（1 人で話す雑談配信など）。コラボ・ゲームの音・BGM が大きい物は避ける。
- アニメの本編のように、BGM や何人もの声が重なる物は、ほとんどの窓が自動で除かれる。
- 1 つのお手本あたり 2 本以上の動画から、合わせて 10 窓以上（できれば 40 窓・約 20 分）。10 窓に届かないお手本は代表値に入らない。
- 音を出したくない時は、板の「音を出す」を外す（YouTube のプレーヤーを消音にすると、測れなくなる）。
- タブを並べて、同時に何人か測れる（同じ人を同じ所で 2 度測った窓は、自動で足されない）。

## 自動で除く窓

- 間に音楽が続く窓、声が 8 秒に満たない窓、雑音が多い・音割れの窓（測る時と `build-voices.ts`）
- 高さが、その人の中央値から 3 半音より外れる窓（別の人や読み上げの声。`build-voices.ts`）
