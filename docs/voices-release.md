# 運営が測った声をサイトに出す

運営が測った声の数字は、リポジトリにコミットしません。1 人 1 件の代表値のファイル（`operator-voices.json`）を作り、GitHub の Release「voices-data」に置きます。サイトを作る時（GitHub Actions）に、そのファイルを取ってきてページに入れます。

- Google の鍵やシートの共有は要りません。
- コミットしないので、消した人の名前と数字が GitHub の記録に残りません。消す時は、その人を除いたファイルに置き換えます。
- サイトに出した声の名前・所属・公式ページ・数字は、公開ページで誰でも見られます（来た人のブラウザーの中で比べるため）。音は入りません。
- Release のファイルも公開です。入れるのは、サイトと同じく名前・所属・公式ページ・数字だけです。人物ID や窓の数は、手元に出る記録だけに出します。

## 手順

1. 出す人の一覧を書く（1 行に 1 人の人物ID。`#` から後は無視）。リポジトリの外か `data/generated/` に置く（コミットしない）。

   ```
   sakura-miko
   kuzuha   # にじさんじ
   ```

2. スプレッドシートを、「ファイル → ダウンロード → Microsoft Excel (.xlsx)」で取ってくる。`data/generated/` に置く（コミットされない）。
   CSV ではなく xlsx にします（CSV は表示の桁に丸まるため）。

3. 代表値を作る。使うタブは「人物一覧」と「声の測定値」です。「追加10分の測定値」（窓が少ない人に足した 10 分）のタブがあれば、その窓も同じ人に足します。

   ```sh
   node tools/voices-release.ts make --sheet data/generated/<ダウンロードした>.xlsx --only <出す人の一覧.txt>
   ```

   - シートには測り方の版が書いていないので、45 項目の見出しが今のサイトとすべて同じ時だけ使います（違えば止まります）。測り方を変えた時は、測り直したシートを使ってください。
   - 収集の書き出し（`snapshot.json`）がある時は、`--sheet` の代わりに `--snapshot <snapshot.json>` も使えます。

   - 人ごとに、使った窓の数と、入れなかった理由が出ます。
   - 窓は、数字のある窓だけを使い、その人の声の高さの中央値から 3 半音より離れた窓を除きます。10 窓に足りない人と、公式ページの URL が無い人は入れません。
   - 測り方の版が今のサイトと違うデータは使いません（止まります）。
   - 作った物は `data/generated/operator-voices.json`。`npx vite` で手元のページに出して確かめられます。
   - 全員を出す時は `--only` の代わりに `--all`。
   - 大枠（VTuber・歌手など。サイトで「VTuber の中で」のように絞って探すための分類）は、「人物一覧」の「大枠」の列から読みます。1 人にいくつでも書けます（例: `VTuber、歌手`）。書ける言葉は `src/data/kinds.ts` の日本語の名前・英語の名前・ID・番号（1〜16）。
   - 「大枠」の列が無い・空の人には、`--kind VTuber` のように付けられます（例: `make --sheet … --all --kind VTuber`）。どちらも無い人は、サイトの「すべて」の中でだけ出ます。
   - 大枠の番号は、データに番号で入るので並べ替えません（`src/data/kinds.ts`。11〜15 は予備、16 はその他）。

4. Release に置いて、サイトを作り直す（公開になるので、決めてから）。

   ```sh
   node tools/voices-release.ts upload --yes
   ```

   `--yes` が無い時は、置く人の一覧を見せるだけで何もしません。知らないオプション（`--help` など）があれば、何もしないで止まります。
   Release「voices-data」が無ければ作り、ファイルを置き換え、サイトの作り直しを始めます。数分で公開ページに出ます。

## 消すお願いが来た時

一覧からその人を消して、3 と 4 をもう一度行います。

## サイトの中でのまとめ方

運営が測った声 → 拡張機能で測った声（`data/catalog.json`・`profiles.json`）→ 利用者の登録の順にまとめ、前にある声と同じ名前の声は後から入れません（`src/data/sources.ts`）。数字は 1 バイトずつに詰めて、ページとは別のファイルにします（`src/data/pack.ts`）。サイトのデータに入るのは、名前・所属・公式ページ・数字だけです（ID は入れません）。
