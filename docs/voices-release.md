# 運営が測った声をサイトに出す

運営が測った声の数字は、リポジトリにコミットしません。1 人 1 件の代表値のファイル（`operator-voices.json`）を作り、GitHub の Release「voices-data」に置きます。サイトを作る時（GitHub Actions）に、そのファイルを取ってきてページに入れます。

- Google の鍵やシートの共有は要りません。
- コミットしないので、消した人の名前と数字が GitHub の記録に残りません。消す時は、登録のシートの「削除」のタブに名前を足し、その人を除いたファイルに置き換えます（下の「消すお願いが来た時」）。
- サイトに出した声の名前・英語名・所属・所属の英語名・大枠・公式ページ・数字は、公開ページで誰でも見られます（来た人のブラウザーの中で比べるため）。英語名は、シートに書いてある人だけです。音は入りません。
- Release のファイルも公開です。入れるのは、サイトと同じく名前・英語名・所属・所属の英語名・大枠・公式ページ・数字だけです。人物ID や窓の数は、手元に出る記録だけに出します。

## 手順

1. 出す人の一覧を書く（1 行に 1 人の人物ID。`#` から後は無視）。リポジトリの外か `data/generated/` に置く（コミットしない）。

   ```
   sakura-miko
   kuzuha   # にじさんじ
   ```

2. スプレッドシートを、「ファイル → ダウンロード → Microsoft Excel (.xlsx)」で取ってくる。`data/generated/` に置く（コミットされない）。
   CSV ではなく xlsx にします（CSV は表示の桁に丸まるため）。

3. 代表値を作る。使うタブは「人物一覧」と「声の測定値」です。「追加10分の測定値」（窓が少ない人に足した 10 分）のタブがあれば、その窓も同じ人に足します。

   ```sh
   node tools/voices-release.ts make --sheet data/generated/<ダウンロードした>.xlsx --only <出す人の一覧.txt>
   ```

   - 45 項目の見出しが今のサイトとすべて同じ時だけ使います（違えば止まります）。
   - 測り方の版: 使えるのは、今の版（`src/voice/measure.ts` の `MEASURE_VERSION`、今は 3.3.0）と、そのまま比べてよい前の版（`MEASURE_COMPATIBLE`、今は 3.1.0 と 3.2.0）だけです。ほかの版の行があれば止まります（まだ測っていない、数字の無い行は見ません）。
   - 「声の測定値」の「測定バージョン」の列は任意です。列が無い・空の行は、列を足す前に測った 3.1.0 として読みます。
   - 「追加10分の測定値」は「測定バージョン」の列が要ります。数字のある行で空なら止まります。
   - 作るファイルには、使った窓の中でいちばん古い版を書きます（今は 3.1.0）。前の版を `MEASURE_COMPATIBLE` から外した時に、その版の数字の入ったファイルでサイトを作らないためです（止まるので、測り直して作り直します）。
   - 収集の書き出し（`snapshot.json`）がある時は、`--sheet` の代わりに `--snapshot <snapshot.json>` も使えます。

   - 人ごとに、使った窓の数と、入れなかった理由が出ます。
   - 窓は、数字のある窓だけを使い、その人の声の高さの中央値から 3 半音より離れた窓を除きます。10 窓に足りない人・氏名が空の人・公式ページの URL が無い人は入れません。
   - サイトでは、名前か英語名がほかの人の名前か英語名と同じ人（ひらがな・カタカナ、全角・半角、空白や記号の違いは同じとみなす）は、人物ID の順で先の 1 人しか出ません。そういう人がいれば、最後に「注意」として人物ID と名前を出します（この記録は手元だけです。サイトのビルドの記録には人数だけが出ます）。シートの氏名・英語名を直してから作り直してください。
   - 作った物は `data/generated/operator-voices.json`。`npx vite` で手元のページに出して確かめられます。
   - 全員を出す時は `--only` の代わりに `--all`。
   - 大枠（VTuber・歌手など。サイトで「VTuber の中で」のように絞って探すための分類）は、「人物一覧」の「大枠」の列から読みます。1 人にいくつでも書けます（例: `VTuber、歌手`）。書ける言葉は `src/data/kinds.ts` の日本語の名前・英語の名前・ID・番号（1〜16）。
   - 「人物一覧」に「英語名」「所属の英語名」の列があれば読みます（どちらも任意。公式の英語の書き方を書きます。自分でローマ字にしない）。英語のページでは英語名を出し、無い人は日本語の名前のままです。声の一覧は、どちらの名前でも探せます。
   - 同じ人の行がいくつかある時は、項目ごと（氏名・所属・公式プロフィール・大枠・英語名など）に、空でない最初の値を使います。
   - 所属の英語名は、画面に出す所属ごとに 1 つです（「ホロライブ4期生」→「ホロライブ」のようにそろえた所属でも 1 つ）。その所属の人の英語名のうち、いちばん多い物を使います。所属をそろえていない人（「現在所属」がそのまま所属の人）の物を先に見て、同じ数なら人物ID の順で先の人の物。書いていない人にも、同じ所属なら同じ英語名が付きます。違う書き方があった時は、記録に出ます。
   - 「大枠」の列が無い・空の人には、`--kind VTuber` のように付けられます（例: `make --sheet … --all --kind VTuber`）。どちらも無い人は、サイトの「すべて」の中でだけ出ます。
   - 大枠の番号は、データに番号で入るので並べ替えません（`src/data/kinds.ts`。11〜15 は予備、16 はその他）。

4. Release に置いて、サイトを作り直す（公開になるので、決めてから）。置き先のリポジトリを `--repo` で必ず書きます（決まった物はありません）。

   ```sh
   node tools/voices-release.ts upload --repo tsukaima-kobo/voice-match --yes
   ```

   - 書けるのは本番（`tsukaima-kobo/voice-match`）と検証用（`tsukaima-kobo/voice-match-dev`）だけです。ほかの名前や、`--repo` が無い時は止まります。最初に「置き先」を大きく出します。
   - `--yes` が無い時は、置き先と置く人の一覧を見せるだけで何もしません。知らないオプション（`--help` など）があれば、何もしないで止まります。
   - Release「voices-data」が無ければ作り、ファイルを置き換え、そのリポジトリのサイトの作り直しを始めます。数分で公開ページに出ます。
   - サイトを作る時、Release のファイルの測り方の版が、今の版でも `MEASURE_COMPATIBLE` の版でもなければ、公開せずに止まります（前のページのまま）。測り方を変えた時は、測り直して 3 と 4 をやり直します。

## 消すお願いが来た時

1. 登録のシート（本番を出した後は「voice-match 声の登録（回答）」）の「削除」のタブに、その人の名前を足します。日本語の名前と、英語名があれば英語名も、1 行に 1 つずつ書きます（書き方は少し違ってもよい。ひらがな・カタカナ、全角・半角、空白や記号の違いは同じ名前とみなします）。
   - 次にサイトを作った時から、その名前の声は、運営が測った声・拡張機能で測った声・利用者の登録のどれからも出なくなります（名前か英語名のどちらかが合えば）。急ぐ時は、Actions の site →「Run workflow」。
   - 利用者が同じ名前で登録した声も出なくなります。Release のファイルを置き直すだけ（2 だけ）では、運営が測った声が消えた次の日に、同じ名前の登録の声が出てしまいます。
2. 出す人の一覧からその人を消して、手順の 3 と 4 をもう一度行います（公開の Release のファイルからも名前と数字を消すため）。4 の `--repo` は、その人が出ているサイトのリポジトリ（本番を出した後は `tsukaima-kobo/voice-match`）にします。
3. 「削除」のタブに書いた名前は、後で消しません（消すと、同じ名前の登録の声がまた出ます）。

「削除」のタブを読むのは、登録の取り込み（`docs/registration.md`）の設定がある時だけです。設定が無いうちは、2 だけを行います。

## サイトの中でのまとめ方

運営が測った声 → 拡張機能で測った声（`data/catalog.json`・`profiles.json`）→ 利用者の登録の順にまとめ、前にある声と同じ名前の声は後から入れません（同じ元の中でも、後の声は入れません）。名前と英語名のどちらかが、前の声の名前か英語名と同じなら同じ声とします（ひらがな・カタカナ、全角・半角、空白や記号の違いは同じとみなします。`src/data/sources.ts`）。登録のシートの「削除」のタブの名前の声は、どの元からも入れません（名前か英語名のどちらかが合えば。その声の名前と英語名の、後の元の声も入れません）。ビルドの記録（公開）には、入れなかった声の人数だけを出します。数字は 1 バイトずつに詰めて、ページとは別のファイルにします（`src/data/pack.ts`）。サイトのデータに入るのは、名前・英語名・所属・所属の英語名・大枠・公式ページ・数字だけです（ID は入れません）。所属の英語名は所属ごとに 1 つで、その所属の声に付いている物のうち、いちばん多い物です。
